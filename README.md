# SPB Bankrot Bot

Telegram-бот и веб-панель для мониторинга лотов недвижимости на торгах по банкротству в **Санкт-Петербурге**.

## Что публикует

Только лоты, которые одновременно:

- недвижимость;
- регион Санкт-Петербург;
- продажа (аренда отфильтровывается);
- торги по банкротству;
- без долевой собственности — в тексте нет слов «доля», «долевой», «долей» (и близких форм).

## Источники

1. **[tbankrot.ru](https://tbankrot.ru)** — агрегатор банкротных ЭТП (реестр площадок: [tbankrot.ru/reestr?type=tp](https://tbankrot.ru/reestr?type=tp)).
2. **ГИС «Торги» (Торги России)** — официальный API `torgi.gov.ru`; если хост недоступен, используется открытое зеркало банкротных лотов.

Новые лоты сохраняются в SQLite и отправляются в Telegram-чат/канал.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
python main.py
```

Панель: `http://127.0.0.1:8765`

### Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Создайте канал или группу, добавьте бота администратором.
3. Узнайте `chat_id` (например через [@userinfobot](https://t.me/userinfobot) или API `getUpdates`).
4. Пропишите значения в `.env` или в секретах Cursor при публикации.

Без токена приложение всё равно сканирует источники и показывает лоты в панели (режим без публикации).

### Переменные окружения

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота | пусто |
| `TELEGRAM_CHAT_ID` | id чата/канала | пусто |
| `PORT` | порт панели | `8765` |
| `SCAN_INTERVAL_SEC` | интервал опроса | `300` |
| `MAX_PAGES_PER_SOURCE` | страниц за проход | `3` |
| `DRY_RUN` | не слать в Telegram | `false` |

## API панели

- `GET /api/status` — статус и счётчики
- `GET /api/lots` — список лотов
- `POST /api/scan` — ручной запуск сканирования
